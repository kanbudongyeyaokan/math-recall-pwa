# 斗破数学

只供个人使用、移动端优先的考研数学做题 PWA。题目、图片、解析、做题记录和斗气进度保存在浏览器 IndexedDB，不需要后端、账号或登录。

在线地址：<https://kanbudongyeyaokan.github.io/math-recall-pwa/>

## 当前功能

- 高数第 1–18 讲地图，可按讲次、讲内板块、经典例题、选择题和课后训练自由开题
- 不设置“今日必须完成多少题”，首页提供讲次入口、从未刷题池随机抽题和快速新增
- 每一讲独立保存随机题序和本轮已刷题；退出、刷新、离线重开后不重复，整讲全部完成才自动洗牌进入下一轮
- 做题会话完整保存在 IndexedDB：每次选项、锁定、揭晓、自评和结算都立即写入，并保留最近 12 个滚动检查点；异常退出后可继续原题
- 每讲设有一场 5 题 Boss 战；必须达到本讲覆盖率、掌握题数和 50% 真实掌握率才解锁，题组优先检验薄弱高区分度题，不能靠重复刷简单题通关
- 完成至少 5 次做题后，三名宿敌会在非做题页面偶发突袭；8 分钟随机完成 5 道选择题，至少 4 道独立命中即可反杀并夺取 66 灵石，失败则触发宿敌嘲讽
- 突发邀战的随机题序、当前进度和绝对截止时间保存在 IndexedDB；刷新、退出或离线重开不会重置倒计时，也不会重复发放胜利奖励
- 剧情、人物、情缘、挑战和任务改由唯一掌握题、订正题与 Boss 首胜构成的“真实掌握力”解锁，重复刷简单题不能推进主线
- 每次做题后仍按 `1 → 3 → 7 → 14 → 30` 天记录建议复做间隔
- 题目图、答案图、来源、页码、标签、核心方法和易错点本机保存
- 开放题、单选题、多选题；选择提交后先反馈命中，再主动揭晓答案
- 每道内置计算题至少两种完整解法，便于比较通法和适用边界
- 搜索题面、来源、方法、错因、选项和解析；按知识点、作答方式筛选
- 新增、编辑、删除；旧版数据库自动升级，用户改过的题不会被种子题覆盖
- 当前 302 道正式考研数学题经过质量审计 2.0；第 1–3 讲已分别逐页扩充到 52、41、41 道经典例题与课后题。全部题目标注 PDF/书页并提供两条独立整理的解析路线；已取消定义题和辨析题，只换数字、字母的同构题及可疑题不会进入随机、挑战或 Boss 题池
- 题库目标是按第 1–18 讲逐页扩充到每讲约 40–50 道、最终约 1000 道；这是持续核验目标，不把已归档模板题计入当前可刷数量
- 每题具备难度、前置知识、预计用时、区分度、来源页码和语义簇；自动检查缺失答案、选择题答案键、重复选项、定理条件及解析闭合性
- 四种自适应模式：基础巩固、薄弱突破、综合混练、模拟冲刺；按知识点掌握度、错题、耗时、自评、提示使用、难度、区分度和久未出现程度动态抽题
- 解析中的 20 个高频定理可直接点击查看条件、结论、标准公式、直觉、误区和例题，包括积分中值定理、三大微分中值定理、Green、Gauss 与 Stokes 公式
- 四档自评：不会、提示后会、独立完成、能够多解
- 斗者、斗师、大斗师、斗灵、斗王、斗皇、斗宗、斗尊、斗圣、斗帝十境界，每境九星
- 行为称号、知识卡掉落、答对欢呼、星阶突破、破境粒子动画、分层做题音效和振动反馈；新成就、人物、挑战与任务各有专属解锁音效

- 做题结算灵石；坊市可购买战衣、气息、武器、配饰和陪伴灵体

- 争锋榜按日模拟三名宿敌的题量与掌握力，刷新不会重复增长；对手会根据境界差距和交锋战绩表现出压制、警惕、虚张声势或服软

- 六门可装备功法，按基础题、选择命中、诚实复盘、独立完成或一题多解触发真实经验与灵石加成
- 三十五个剧情抉择、人物羁绊阶段和等价奖励路线；选择会进入完整备份

- 安装诊断页会逐项检查 HTTPS、Manifest、Service Worker、离线缓存、持久存储、桌面安装与网络；更新前自动保存恢复点，失败时旧版本仍可继续使用
- Service Worker 离线启动、手机桌面安装、前台自动检查更新和一键升级

## 手机使用

优先在 Safari 或 Chrome 打开在线地址，再安装到桌面。这样日常入口、离线缓存和本地记录最稳定。

- 微信：链接可以直接打开和刷题。安装时点右上角菜单，选择“在浏览器打开”。
- iPhone：在 Safari 点“分享”，选择“添加到主屏幕”。
- Android：在 Chrome 或系统浏览器菜单选择“安装应用”，支持时也会显示应用内安装按钮。

微信、Safari、Chrome 和不同域名使用彼此隔离的 IndexedDB。在微信里产生的记录不会自动出现在 Safari 中。若要换浏览器，先在“洞府 → 数据保险箱”导出，再到目标浏览器导入。

## 数据不会因普通更新消失

应用代码和个人数据分开存储。在线升级只替换缓存中的应用文件，不会覆盖 IndexedDB 中的题目、图片和做题记录。普通刷新、关闭页面、离线启动和安装更新都会保留记录。

应用还会：

- 启动时申请 `navigator.storage.persist()`，降低浏览器自动回收数据的概率；
- 作答过程中保存最近 12 个会话检查点，完成做题、编辑、删除或导入前后另建数据恢复点；
- 删除题卡前先建立恢复点；
- 可导出包含图片、题目、解析、历史、每讲刷题轮次、个人头像、灵石、装备、境界、称号和奖励卡的 AES-256-GCM 加密完整备份，并在不改动本机数据的情况下检测可恢复性。

浏览器本地存储无法提供绝对不丢失保证。清除站点数据、使用无痕模式、卸载浏览器或设备损坏仍可能删除本机副本，因此建议每周导出一次，并放入自己的电脑或网盘。

## 本地运行

需要 Node.js 20+，推荐 Node.js 22。

```bash
corepack enable
pnpm install
pnpm dev
```

浏览器打开终端给出的地址，默认是 <http://localhost:5173>。同一局域网的手机可使用：

```bash
pnpm dev --host 0.0.0.0
```

相机、安装和 Service Worker 在非 `localhost` 环境通常要求 HTTPS，长期使用应部署到 GitHub Pages。

## 部署到 GitHub Pages

仓库内的 [deploy.yml](.github/workflows/deploy.yml) 会在每次推送 `main` 后自动测试、构建并发布。

1. 在 GitHub 新建仓库，并把项目推送到 `main`。
2. 打开 `Settings → Pages`。
3. 将 `Build and deployment → Source` 设为 `GitHub Actions`。
4. 等待 `Deploy Math Recall PWA to Pages` 工作流完成。
5. 打开 `https://<用户名>.github.io/<仓库名>/`。

工作流会根据仓库名自动设置 Vite `base`。手动构建子路径版本可用：

```powershell
$env:VITE_BASE_PATH='/仓库名/'
pnpm build
```

## 加入自己的题和书页

手机端从首页“录入新题”或题库页新增，可直接拍题目与答案，也可只录文字。多方法解析支持继续增加路线。

也可以把你已购买教辅中的题目截图、分析页或章节关键点发给 Codex。本项目会按以下结构整理后写入个人题库：

- 题面与来源页码
- 知识点和前置定义
- 正确答案与完整推导
- 至少两种经典有效方法（适用时）
- 易错点、失效条件和复做提示
- 单选或多选选项与答案键（适用时）

少量内容可直接加入代码；批量内容也可生成兼容的备份 JSON，在应用内一次导入。

### 旧私人千题包迁移

早期 `何耀焜-张宇基础30讲高数-1000卡.json` 使用批量模板生成。审计发现其中按核心方法归一化后有 628 张重复卡，继续混入随机池会造成“只换数字、解法相同”的无效练习。v0.14.0 会按稳定 ID `zy30-heyaokun-001`–`1000` 和精确来源双重匹配，将这批旧卡自动归档；只匹配其中一个条件的个人新增题不会受影响。

归档不是删除。旧卡及其做题次数、间隔、日志和奖励关系继续留在 IndexedDB 中，玩家经验、灵石、功法、羁绊、称号和角色档案不会回退。以后误导入旧包时，这批卡仍会保持归档。v0.26.0 当前内置正式题池为 302 道；旧模板卡、定义题、辨析题和待人工确认题均不计入这个数字。

公式使用 LaTeX 定界符：行内公式写成 `$f'(x)$`，独立公式写成 `$$\int_a^b f(x)\,dx$$`。做题页会自动用 KaTeX 清晰排版。

## 题库来源与版权

内置题不是对张宇、武忠祥或 660 原题的公开复制，也不从网络抓取商业教辅。v0.14.0 使用何耀焜自购的《核心计算通关讲义》和《1000 题数一解析册》扫描件定位章节、考点、页码范围和解法线索；v0.19.0 继续用自购的《武忠祥高数基础篇做题本》建立章节和方法索引，再重新命制题面、选项与双路线解析。扫描页、PDF 和 OCR 临时文件不会提交到公开 Git 仓库。

你可以为个人学习上传自己合法购买书籍的页面。不要把含商业书页原图的个人备份公开发布，也不要把这些图片提交到公开 GitHub 仓库。

## 技术结构

- Vite + React + TypeScript
- Dexie.js / IndexedDB：题卡、Blob 图片、做题日志、奖励、档案、设置和恢复点
- vite-plugin-pwa / Workbox：Manifest、离线缓存和在线升级
- Lucide React：统一图标
- KaTeX / React KaTeX：可缩放、可横向查看的数学公式排版
- Vitest + fake-indexeddb：领域逻辑和数据库迁移测试
