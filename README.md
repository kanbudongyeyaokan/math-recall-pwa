# 斗破数学

只供个人使用、移动端优先的考研数学做题 PWA。题目、图片、解析、做题记录和斗气进度保存在浏览器 IndexedDB，不需要后端、账号或登录。

在线地址：<https://kanbudongyeyaokan.github.io/math-recall-pwa/>

## 当前功能

- 高数第 1–18 讲地图，可按讲次、讲内板块、定义、经典例题、选择题和课后训练自由开题
- 不设置“今日必须完成多少题”，首页提供讲次入口、从未刷题池随机抽题和快速新增
- 每一讲独立保存随机题序和本轮已刷题；退出、刷新、离线重开后不重复，整讲全部完成才自动洗牌进入下一轮
- 每次做题后仍按 `1 → 3 → 7 → 14 → 30` 天记录建议复做间隔
- 题目图、答案图、来源、页码、标签、核心方法和易错点本机保存
- 开放题、单选题、多选题；选择提交后先反馈命中，再主动揭晓答案
- 每道内置计算题至少两种完整解法，便于比较通法和适用边界
- 搜索题面、来源、方法、错因、选项和解析；按卡片类型、知识点、作答方式筛选
- 新增、编辑、删除；旧版数据库自动升级，用户改过的题不会被种子题覆盖
- 698 道去重后的考研数学题，含 624 道资料考点重构题，覆盖高数 18 讲、线代与概率统计
- 四档自评：不会、提示后会、独立完成、能够多解
- 斗者、斗师、大斗师、斗灵、斗王、斗皇、斗宗、斗尊、斗圣、斗帝十境界，每境九星
- 行为称号、知识卡掉落、答对欢呼、星阶突破、破境粒子动画、分层做题音效和振动反馈；新成就、人物、挑战与任务各有专属解锁音效
- 角色语音覆盖奖励结算、剧情对话、人物档案与羁绊抉择；可分别调节音效、语音、自动播报、音量和语速
- 何耀焜实名档案、原创年轻数学修炼者、个人头像与交大斗魂剧情
- 做题结算灵石；坊市可购买战衣、气息、武器、配饰和陪伴灵体
- 六门可装备功法，按概念题、选择命中、诚实复盘、独立完成或一题多解触发真实经验与灵石加成
- 十二个剧情抉择、人物羁绊阶段和等价奖励路线；选择会进入完整备份
- 曾宇鑫、袁越、陈睿斌三名宿敌与陈彦君、美杜莎、小医仙三条情缘线；陈彦君拥有五段贯穿主线的剧情
- 人物原画可点击打开完整档案，查看背景、目标、初遇、代表台词和当前关系；当前说话者、档案入场与羁绊奖励带有克制动画
- KaTeX 数学公式排版，题面、选项、答案和多方法解析均支持 `$...$` 与 `$$...$$`
- 浏览器持久存储申请、最近 5 个本机恢复点、完整 JSON 导入导出
- Service Worker 离线启动、手机桌面安装、前台自动检查更新和一键升级

## 手机使用

优先在 Safari 或 Chrome 打开在线地址，再安装到桌面。这样日常入口、离线缓存和本地记录最稳定。

- 微信：链接可以直接打开和刷题。安装时点右上角菜单，选择“在浏览器打开”。
- iPhone：在 Safari 点“分享”，选择“添加到主屏幕”。
- Android：在 Chrome 或系统浏览器菜单选择“安装应用”，支持时也会显示应用内安装按钮。

微信、Safari、Chrome 和不同域名使用彼此隔离的 IndexedDB。在微信里产生的记录不会自动出现在 Safari 中。若要换浏览器，先在“洞府 → 数据保险箱”导出，再到目标浏览器导入。

## 数据不会因普通更新消失

应用代码和个人数据分开存储。在线升级只替换缓存中的应用文件，不会覆盖 IndexedDB 中的题目、图片和做题记录。普通刷新、关闭页面、离线启动和安装更新都会保留记录。

应用还会：

- 启动时申请 `navigator.storage.persist()`，降低浏览器自动回收数据的概率；
- 完成做题、编辑或导入后保存最近 5 个轻量恢复点；
- 删除题卡前先建立恢复点；
- 导出包含图片、题目、解析、历史、每讲刷题轮次、个人头像、灵石、装备、境界、称号和奖励卡的完整备份。

浏览器本地存储无法提供绝对不丢失保证。清除站点数据、使用无痕模式、卸载浏览器或设备损坏仍可能删除本机副本，因此建议每周导出一次，并放入自己的电脑或网盘。

## 本地运行

需要 Node.js 20+，推荐 Node.js 22。

```bash
corepack enable
pnpm install
pnpm dev
```

浏览器打开终端给出的地址，默认是 <http://localhost:5173>。同一局域网的手机可使用：

```bash
pnpm dev --host 0.0.0.0
```

相机、安装和 Service Worker 在非 `localhost` 环境通常要求 HTTPS，长期使用应部署到 GitHub Pages。

## 部署到 GitHub Pages

仓库内的 [deploy.yml](.github/workflows/deploy.yml) 会在每次推送 `main` 后自动测试、构建并发布。

1. 在 GitHub 新建仓库，并把项目推送到 `main`。
2. 打开 `Settings → Pages`。
3. 将 `Build and deployment → Source` 设为 `GitHub Actions`。
4. 等待 `Deploy Math Recall PWA to Pages` 工作流完成。
5. 打开 `https://<用户名>.github.io/<仓库名>/`。

工作流会根据仓库名自动设置 Vite `base`。手动构建子路径版本可用：

```powershell
$env:VITE_BASE_PATH='/仓库名/'
pnpm build
```

v0.6.0 起 Service Worker 会在前台恢复时主动检查并自动获取新版本；必要时顶部仍会出现“立即升级”。“洞府 → 版本与在线升级”也可手动检查。升级只替换应用缓存，个人 IndexedDB 数据保持不变。

v0.7.0 会把旧版父母、宿敌和情缘角色 ID 自动迁移到新版阵容，旧羁绊点数与已选情缘路线一并保留。

v0.10.0 起，每一讲使用独立且持久化的随机轮次：已完成题在本轮不再出现，只有整讲全部完成后才开始下一轮；音效、语音与自动播报设置同样保存在当前浏览器中。

v0.12.0 将高数公开原创题库扩展到 76 题，新增覆盖 18 讲的 36 道定义与基础结论选择题，每题提供条件链和反例检验两种解析。人物志扩展到 22 人，7 位核心角色拥有待机、对白、鼓励和对峙四种镜头；讲次卡片支持手机双击或桌面双击直接随机开题。角色语音会识别系统中文音色、分配人物声线，并在缺少语音包时显示设备安装路径。

v0.13.0 为坊市全部 24 件服装、光环、武器、配饰和伙伴加入独立的高质量游戏道具插画，并重制曾宇鑫、袁越、陈睿斌的反派主立绘与四种动作。升级只替换应用资源，不会改动物品 ID、已购记录或 IndexedDB 刷题进度。

v0.14.0 将可用题库扩展到 698 道。新增 624 道题来自《核心计算通关讲义》和《1000 题数一解析册》的考点、页码与解法线索重构，使用 624 个唯一方法指纹；升级时自动归档旧私人千题包与两道重复内置题，但保留旧题本体、做题日志、经验、灵石和人物进度。新成就、新人物、新挑战和新任务首次解锁时会播放各自的专属音效。

v0.11.0 优化手机端长解析阅读：答案、各解法、核心方法和易错点可独立折叠，块级公式可横向滚动并进入全屏缩放查看。音效和角色语音支持 1% 精度调节、快捷预设和即时试听，设置会在当前浏览器持久保存；坊市商品、灵石和 18 个称号也增加了独立的游戏化插画与徽章。

## 加入自己的题和书页

手机端点“新增”，可直接拍题目与答案，也可只录文字。多方法解析支持继续增加路线。

也可以把你已购买教辅中的题目截图、分析页或章节关键点发给 Codex。本项目会按以下结构整理后写入个人题库：

- 题面与来源页码
- 知识点和前置定义
- 正确答案与完整推导
- 至少两种经典有效方法（适用时）
- 易错点、失效条件和复做提示
- 单选或多选选项与答案键（适用时）

少量内容可直接加入代码；批量内容也可生成兼容的备份 JSON，在应用内一次导入。

### 旧私人千题包迁移

早期 `何耀焜-张宇基础30讲高数-1000卡.json` 使用批量模板生成。审计发现其中按核心方法归一化后有 628 张重复卡，继续混入随机池会造成“只换数字、解法相同”的无效练习。v0.14.0 会按稳定 ID `zy30-heyaokun-001`–`1000` 和精确来源双重匹配，将这批旧卡自动归档；只匹配其中一个条件的个人新增题不会受影响。

归档不是删除。旧卡及其做题次数、间隔、日志和奖励关系继续留在 IndexedDB 中，玩家经验、灵石、功法、羁绊、称号和角色档案不会回退。以后误导入旧包时，这批卡仍会保持归档。当前随机题池由 698 道质量门禁通过题提供。

公式使用 LaTeX 定界符：行内公式写成 `$f'(x)$`，独立公式写成 `$$\int_a^b f(x)\,dx$$`。做题页会自动用 KaTeX 清晰排版。

## 题库来源与版权

内置题不是对张宇、武忠祥或 660 原题的公开复制，也不从网络抓取商业教辅。v0.14.0 使用何耀焜自购的《核心计算通关讲义》和《1000 题数一解析册》扫描件定位章节、考点、页码范围和解法线索，再重新命制题面、选项与双路线解析。扫描页、PDF 和 OCR 临时文件不会提交到公开 Git 仓库。

你可以为个人学习上传自己合法购买书籍的页面。不要把含商业书页原图的个人备份公开发布，也不要把这些图片提交到公开 GitHub 仓库。

## 技术结构

- Vite + React + TypeScript
- Dexie.js / IndexedDB：题卡、Blob 图片、做题日志、奖励、档案、设置和恢复点
- vite-plugin-pwa / Workbox：Manifest、离线缓存和在线升级
- Lucide React：统一图标
- KaTeX / React KaTeX：可缩放、可横向查看的数学公式排版
- Vitest + fake-indexeddb：领域逻辑和数据库迁移测试

关键文件：

- `src/db.ts`：Dexie v7、去重迁移、图片压缩、做题事务、功法与剧情结算、持久化与恢复点
- `src/domain/scheduler.ts`：间隔算法
- `src/domain/gamification.ts`：斗气境界、称号、经验、灵石、坊市和掉落
- `src/domain/cultivation.ts`：六门功法、解锁条件、触发判定、熟练度与加成
- `src/domain/encounters.ts`：剧情抉择、等价奖励与人物羁绊
- `src/domain/curriculum.ts`：高数 18 讲、讲内板块和题目分类映射
- `src/domain/practiceCycle.ts`：按讲保存的随机题序、已刷集合与整讲轮次重置
- `src/domain/story.ts`：让父母过上更好生活的交大主线、16 人角色志、朋友与宿敌剧情，以及三条独立情缘路线
- `public/characters/`：A 前期修炼服、C 主角标准形象、B 交大学院皮肤和全部剧情角色原画
- `src/data/seed.ts` / `src/data/banks/`：698 道题入口、156 个知识方法节点与 624 道资料考点重构题
- `src/data/questionQuality.ts`：方法指纹去重、公式抽取和旧私人题包精确识别
- `src/utils/backup.ts`：v1/v2 完整备份与恢复
- `src/utils/sound.ts` / `src/utils/voice.ts`：分层战斗音效、角色声线与本地偏好
- `src/pages/PracticePage.tsx`：18 讲地图与做题范围选择
- `src/pages/ReviewPage.tsx`：连续做题队列、答案门槛、选择判分、多解和自评
