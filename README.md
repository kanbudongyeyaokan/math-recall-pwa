# 斗破数学

只供个人使用、移动端优先的考研数学经典题复习 PWA。题目、图片、解析、复习记录和斗气进度保存在浏览器 IndexedDB，不需要后端、账号或登录。

在线地址：<https://kanbudongyeyaokan.github.io/math-recall-pwa/>

## 当前功能

- 今日待复习、随机抽题、快速新增和固定 `1 → 3 → 7 → 14 → 30` 天间隔
- 题目图、答案图、来源、页码、标签、核心方法和易错点本机保存
- 开放题、单选题、多选题；选择提交后先反馈命中，再主动揭晓答案
- 每道内置计算题至少两种完整解法，便于比较通法和适用边界
- 搜索题面、来源、方法、错因、选项和解析；按卡片类型、知识点、作答方式筛选
- 新增、编辑、删除；旧版数据库自动升级，用户改过的题不会被种子题覆盖
- 40 张原创考纲同型卡，覆盖高数、线代、概率的高频板块
- 四档自评：不会、提示后会、独立完成、能够多解
- 斗者、斗师、大斗师、斗灵、斗王、斗皇、斗宗、斗尊、斗圣、斗帝十境界，每境九星
- 行为称号、知识卡掉落、星阶突破、破境动效和振动反馈
- 何耀焜实名档案、个人头像、原创修炼形象、灵石结算和可购买装备的坊市
- KaTeX 数学公式排版，题面、选项、答案和多方法解析均支持 `$...$` 与 `$$...$$`
- 浏览器持久存储申请、最近 5 个本机恢复点、完整 JSON 导入导出
- Service Worker 离线启动、手机桌面安装、新版本可用提示

## 手机使用

优先在 Safari 或 Chrome 打开在线地址，再安装到桌面。这样日常入口、离线缓存和本地记录最稳定。

- 微信：链接可以直接打开和刷题。安装时点右上角菜单，选择“在浏览器打开”。
- iPhone：在 Safari 点“分享”，选择“添加到主屏幕”。
- Android：在 Chrome 或系统浏览器菜单选择“安装应用”，支持时也会显示应用内安装按钮。

微信、Safari、Chrome 和不同域名使用彼此隔离的 IndexedDB。在微信里产生的记录不会自动出现在 Safari 中。若要换浏览器，先在“战绩 → 数据保险箱”导出，再到目标浏览器导入。

## 数据不会因普通更新消失

应用代码和个人数据分开存储。在线升级只替换缓存中的应用文件，不会覆盖 IndexedDB 中的题目、图片和复习记录。普通刷新、关闭页面、离线启动和安装更新都会保留记录。

应用还会：

- 启动时申请 `navigator.storage.persist()`，降低浏览器自动回收数据的概率；
- 完成复习、编辑或导入后保存最近 5 个轻量恢复点；
- 删除题卡前先建立恢复点；
- 导出包含图片、题目、解析、历史、个人头像、灵石、装备、境界、称号和奖励卡的完整备份。

浏览器本地存储无法提供绝对不丢失保证。清除站点数据、使用无痕模式、卸载浏览器或设备损坏仍可能删除本机副本，因此建议每周导出一次，并放入自己的电脑或网盘。

## 本地运行

需要 Node.js 20+，推荐 Node.js 22。

```bash
corepack enable
pnpm install
pnpm dev
```

浏览器打开终端给出的地址，默认是 <http://localhost:5173>。同一局域网的手机可使用：

```bash
pnpm dev --host 0.0.0.0
```

相机、安装和 Service Worker 在非 `localhost` 环境通常要求 HTTPS，长期使用应部署到 GitHub Pages。

## 部署到 GitHub Pages

仓库内的 [deploy.yml](.github/workflows/deploy.yml) 会在每次推送 `main` 后自动测试、构建并发布。

1. 在 GitHub 新建仓库，并把项目推送到 `main`。
2. 打开 `Settings → Pages`。
3. 将 `Build and deployment → Source` 设为 `GitHub Actions`。
4. 等待 `Deploy Math Recall PWA to Pages` 工作流完成。
5. 打开 `https://<用户名>.github.io/<仓库名>/`。

工作流会根据仓库名自动设置 Vite `base`。手动构建子路径版本可用：

```powershell
$env:VITE_BASE_PATH='/仓库名/'
pnpm build
```

有新版本时应用顶部会出现“立即升级”。确认后页面重新加载，个人 IndexedDB 数据保持不变。

## 加入自己的题和书页

手机端点“新增”，可直接拍题目与答案，也可只录文字。多方法解析支持继续增加路线。

也可以把你已购买教辅中的题目截图、分析页或章节关键点发给 Codex。本项目会按以下结构整理后写入个人题库：

- 题面与来源页码
- 知识点和前置定义
- 正确答案与完整推导
- 至少两种经典有效方法（适用时）
- 易错点、失效条件和复做提示
- 单选或多选选项与答案键（适用时）

少量内容可直接加入代码；批量内容也可生成兼容的备份 JSON，在应用内一次导入。

### 导入私人《基础 30 讲》整理包

私人资料包不会提交到公开 Git 仓库。生成后在“战绩 → 数据保险箱”选择“导入备份”，保持“导入前清空本机数据”关闭，即可按稳定 ID 合并题卡并保留已有进度、图片、灵石和称号。重复导入同一包不会产生重复卡片。

公式使用 LaTeX 定界符：行内公式写成 `$f'(x)$`，独立公式写成 `$$\int_a^b f(x)\,dx$$`。复习页会自动用 KaTeX 清晰排版。

## 题库来源与版权

内置 40 卡不是张宇、武忠祥或 660 的原题，也不从网络盗取商业教辅。它们依据公开考研数学范围和高频题型重新命制，考点覆盖参考了[中国研究生招生信息网的高数、线代、概率高频题型说明](https://yz.chsi.com.cn/kyzx/math/201709/20170926/1630782140.html)。

你可以为个人复习上传自己合法购买书籍的页面。不要把含商业书页原图的个人备份公开发布，也不要把这些图片提交到公开 GitHub 仓库。

## 技术结构

- Vite + React + TypeScript
- Dexie.js / IndexedDB：题卡、Blob 图片、复习日志、奖励、档案、设置和恢复点
- vite-plugin-pwa / Workbox：Manifest、离线缓存和在线升级
- Lucide React：统一图标
- KaTeX / React KaTeX：可缩放、可横向查看的数学公式排版
- Vitest + fake-indexeddb：领域逻辑和数据库迁移测试

关键文件：

- `src/db.ts`：Dexie v4、迁移、图片压缩、复习事务、灵石与装备、持久化与恢复点
- `src/domain/scheduler.ts`：间隔算法
- `src/domain/gamification.ts`：斗气境界、称号、经验、灵石、坊市和掉落
- `src/data/seed.ts`：40 张原创考纲同型卡
- `src/utils/backup.ts`：v1/v2 完整备份与恢复
- `src/pages/ReviewPage.tsx`：答案门槛、选择判分、多解和自评
